# watari

Data fetching for React and React Native: a middleware pipeline and a tag-based cache that lives in the store you already use (memory, Redux, Zustand).

> Work in progress.

```sh
yarn add @watari/core @watari/react
```

| Package | |
|---|---|
| `@watari/core` | Client, cache, middleware pipeline |
| `@watari/react` | React bindings |
| `@watari/redux` | Redux cache store |
| `@watari/zustand` | Zustand cache store |
| `@watari/middlewares` | Auth refresh, retry, ... |
